# Rust Inventory (Forge 1.12.2) — аддон к MineRust Addons

## Что делает
- На **E** открывается инвентарь в стиле Rust (без модельки/скина игрока):
  слева — ник, здоровье, защита, слот второй руки и **7 слотов одежды**; справа — **ИНВЕНТАРЬ 6×4** и **ПОЯС 6**.
- Хотбар — **6 слотов** вместо 9 (клавиши 7/8/9 отключены, колесо мыши крутит 1–6). Слоты 7–9 хотбара и 3 слота инвентаря заблокированы (в сундуках они затемнены).
- Одежда слоями, как в Rust: футболка + кофта/куртка + нагрудник одновременно. Нельзя надеть 2 нагрудника (металл + металл, металл + деревянный, металл + из знаков и т.д.).
- ПКМ бронёй в руке — надеть в свободный слот одежды. Если конфликт — пишет, с чем.
- Вся надетая одежда рисуется на игроке слоями (свои текстуры и модели из MineRust), её видят и другие игроки.
- Защита всех вещей суммируется, вещи изнашиваются, эффекты брони (onArmorTick) работают. При смерти одежда выпадает.
- В творческом режиме на E — ванильный инвентарь, Rust-инвентарь на **I** (меняется в настройках управления).

## Сборка
**Вариант 1 — GitHub:** залей содержимое архива в репозиторий → вкладка Actions → «Build mod» → скачай артефакт `RustInventory-jar`.

**Вариант 2 — свой MDK:** скопируй `src/main/java/com/rustinv` и `src/main/resources` в свой проект Forge 1.12.2 (MDK 14.23.5.2860) и запусти `gradlew build`. Готовый jar — в `build/libs`.

Клади jar в `mods/` вместе с `MineRust_Addons_Mod_2.5-rustfix13-allguns.jar`.

## Слои одежды
Каждая вещь занимает зоны. Две вещи с общей зоной надеть нельзя.

| Зона | Примеры |
|---|---|
| TORSO_UNDER | футболки, белая рубашка, бра |
| TORSO_JACKET | Clothkit jacket, кожаная куртка, Vagabond, снежная куртка |
| TORSO_ARMOR | металлический, деревянный, из знаков, костяной, тяжёлый нагрудник |
| HEAD_OUTER/ARMOR | шапки (OUTER); шлемы — OUTER+ARMOR; металл. маска — ещё FACE_ARMOR |
| FACE_UNDER | бандана, балаклава |
| LEGS_UNDER / LEGS_ARMOR | штаны/шорты/джинсы / поножи |
| FEET, HANDS, BACK | обувь, перчатки, баллон для дайвинга |
| хазмат, костюм кролика | занимают сразу все зоны торса/ног/головы |

Менять можно в `config/rustinventory.cfg` → `clothingOverrides`, например:
`minerustaddons:clothkitbody=TORSO_JACKET,ARMS_JACKET`

## Ограничения
- Процедуры MCreator, которые проверяют ванильный слот брони (например, «надет ли хазмат» для радиации), не увидят вещь в Rust-слотах. Такие процедуры нужно поменять на проверку через этот мод или привязать к onArmorTick.
